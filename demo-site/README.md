# Независимое демо для GitHub Pages

Статическая страница «Линия дома» не использует Tilda: `index.html`, `app.js`, `api-config.js` и изображения можно публиковать из корня отдельной ветки GitHub Pages. Страница — демонстрация вымышленной компании; изображения являются визуализациями, а не примерами выполненного ремонта. Существующий сайт Tilda эта версия не изменяет.

Форма не собирает имя и телефон. Она отправляет только выбранные параметры ремонта на отдельный демонстрационный шлюз; тот подставляет фиксированные синтетические имя и телефон, генерирует идентификатор и передаёт событие существующему приёмнику с серверным ключом. Публичная страница не содержит ключа. Полученный ответ означает только сохранение заявки, не создание сделки или доставку Telegram. Повторные заявки по одному телефону и услуге могут объединяться по правилам проекта.

## Локальный шлюз

`app/api/demo_gateway.py` предназначен только для тестовых данных. Он принимает только `service`, `area`, `budget`, отклоняет неизвестные поля и не принимает произвольный текст. Допустимые Origin задаются администратором; это ограничение браузеров, а не надёжная аутентификация. Глобальный лимит — 12 запросов за час на процесс, в памяти и без сохранения после перезапуска. Это снижает, но не исключает спам или блокировку лимита сторонним отправителем. Шлюз не предназначен для реальных пользователей или персональных данных. Он не пересылает секрет при HTTP-редиректе.

Для отдельного стенда используйте `infra/pages-demo/compose.yaml`: потребуется работающий приёмник и существующая сеть `remont-trial_default`. Перед запуском создайте защищённый env-файл вне Git, где `WEBHOOK_KEY` совпадает с ключом приёмника, а `DEMO_ALLOWED_ORIGINS` содержит через запятую точные HTTPS-origin опубликованного сайта (схема и домен без пути). Для локального просмотра можно добавить `http://127.0.0.1:18766`. Не публикуйте env-файл и не выводите развёрнутую Compose-конфигурацию с секретом.

```sh
docker compose --env-file /ЗАЩИЩЁННЫЙ/ФАЙЛ -f infra/pages-demo/compose.yaml up -d --build
```

Не запускайте второй экземпляр, если демонстрационный шлюз уже запущен вручную или порт `18767` занят. Контейнер туннеля выводит публичный HTTPS-адрес в собственный лог. Этот адрес можно указать в `api-config.js` без завершающего `/`; он не является секретом. Затем обновите опубликованную статическую страницу. Туннель без аккаунта временный: после пересоздания адрес изменится, а пока сайт продолжает ссылаться на старый адрес, форма не будет работать. Настоящее постоянство требует отдельно настроенного именованного туннеля и DNS.

GitHub Pages хранит и отдаёт только статику. Если Mac, Docker, туннель, приёмник или интеграции остановлены, страница может открываться, но форма либо дальнейшая обработка будут недоступны. Используйте только вымышленные данные; для реальных заявок нужны отдельная защита и проверенная инфраструктура. Не переносите секрет `WEBHOOK_KEY` в JavaScript или в репозиторий.
