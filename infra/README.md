# Инфраструктура

Корневой `compose.yaml` предназначен для локального стенда. Миграции хранятся в `migrations/`; порядок запуска и ограничения старых баз описаны в `docs/migrations.md`. Production-конфигурация и восстановление резервной копии ещё должны быть подготовлены и проверены до развёртывания на VPS.
