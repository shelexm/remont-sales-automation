# Инфраструктура

Корневой `compose.yaml` предназначен для локального стенда. Миграции хранятся в `migrations/`; порядок запуска и ограничения старых баз описаны в `docs/migrations.md`. [Резервные копии и проверка восстановления](backup/README.md) покрывают отдельно PostgreSQL заявок и MariaDB CRM. Копирование файлов EspoCRM, n8n и согласованное восстановление всей системы ещё не реализованы.
