# Инфраструктура

Корневой `compose.yaml` предназначен для локального стенда. Миграции хранятся в `migrations/`; порядок запуска и ограничения старых баз описаны в `docs/migrations.md`. [Резервные копии и проверки](backup/README.md) отдельно покрывают PostgreSQL заявок, MariaDB и файлы CRM, а также SQLite n8n. Ключи и дополнительные файлы не собраны в общий бэкап; согласованное восстановление всей системы ещё не проверено.
