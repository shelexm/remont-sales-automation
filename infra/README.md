# Инфраструктура

Корневой `compose.yaml` предназначен для локального стенда. Миграции хранятся в `migrations/`; порядок запуска и ограничения старых баз описаны в `docs/migrations.md`. [Резервные копии и проверки](backup/README.md) отдельно покрывают PostgreSQL заявок, MariaDB и файлы CRM, а также SQLite n8n. Ключ n8n и минимальные параметры восстановления сохраняются отдельно. Изолированное восстановление с вымышленной заявкой проверено; копии сняты в разное время, поэтому согласованность всей истории, Tilda и Telegram при восстановлении не подтверждена.
