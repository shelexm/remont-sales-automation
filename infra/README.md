# Инфраструктура

Корневой `compose.yaml` предназначен для локального стенда. Миграции хранятся в `migrations/`; порядок запуска и ограничения старых баз описаны в `docs/migrations.md`. [Резервная копия и проверка восстановления](backup/README.md) покрывают только PostgreSQL заявок. Production-конфигурация, резервирование EspoCRM/n8n и проверка согласованного восстановления всей системы ещё должны быть подготовлены до развёртывания на VPS.
