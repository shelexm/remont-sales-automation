# План и критерии приёмки

1. Foundation: отдельная feature-ветка, документация, автоматические проверки и PR. Review владельца перед слиянием.
2. Основной процесс: валидация, нормализация, сохранение, идемпотентность, очередь и контролируемое восстановление; тесты ошибок и перезапуска.
3. Интеграции: тестовый и EspoCRM-адаптеры, Telegram, контроль статусов и отчётность. Проверки с моками и, отдельно, с работающими сервисами.
4. Tilda: мобильный лендинг с согласием и реальная сквозная отправка заявки; при недоступности редактора — материалы для сборки.
5. VPS: аудит, резервное копирование и план отката; развёртывание только после отдельного разрешения.
6. Портфолио: PR в STAKKO после завершения проекта; текущий кейс не изменяется.

Дополнительные адаптеры CRM будут отдельными задачами. Их поддержка не считается реализованной до разработки и проверки с соответствующей CRM.
